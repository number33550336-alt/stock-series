# Stock Time-Series Analysis

A small Python toolkit for exploring how a stock moves in relation to market indices and ETFs.

- Download stock and benchmark price data and compare current and rolling R-squared values.
- Plot regression residuals and return differences between a stock and a benchmark.

# 股票时间序列分析

一个用于分析个股与市场指数、ETF 关系的 Python 小工具。

- 下载股票和基准资产的价格数据，比较当前及滚动 R²。
- 绘制回归残差，以及个股与基准资产之间的收益差。
